## 4. Test-coverage assessment

**Strong.** The matched `build_plan` path has direct refusal tests for every documented code, an allocation-fence test, an idle-rank deadlock test with an honestly-documented MPICH limitation, a differential oracle (peer plan vs matched plan), partial-overlap delivery, and the hook-path gap *pinned as known-broken* rather than hidden. `CommGraph` covers all three overlap shapes × both match modes, the NN tolerance boundary, SFC locality/population assertions, dup-id/no-match refusals, zero-entity and bystander ranks. Crystal router has rounds/empty/latency/out-of-range tests. Connect has tier-0 tests for every pure rule with mutation-kill annotations, plus a host-run executable pair. LowFive covers all tier-0-reachable refusals and explicitly documents the never-exercised distributed half.

**Gaps, in priority order:**
1. **No test can catch TR-1**: `DisagreeingHalvesAreRefusedBeforeTheRun` passes Phase A on *all* ranks, so the asymmetric-Phase-A-failure → skipped-`Alltoall` hang is unreachable by the suite. A two-rank test where rank 0's send plan names rank 2 of a 2-rank communicator (Phase A fails on rank 0 only) would hang today instead of returning `E-TRANSPORT-RANKS` everywhere — which is the test's own failure signature.
2. **TR-2/TR-4**: the `fuse-lowfive-vol` plugin has no runtime test at all (blocked by D14's libfmt issue on this host) — the world-collective deadlock would surface on the first host run of the documented `lowfive.mpmd.3` row.
3. **TR-17**: D18's third-component refusal has no firing test anywhere.
4. Minor: no test for `E-TRANSPORT-ALLOC` (needs injected `bad_alloc`); no test that `CopyTransport` and `MpiTransport` agree on the null-when-empty contract (TR-16); the whole `test/parallel` suite remains host-run items (KNOWN_ISSUES C1).
