## 2. Checked and found clean

- **Schur slab solver, the numerics.** Slab assembly one-pass bucketing, interface ordering, `A_GI` read as `a_ig.transpose()` everywhere it is used, allgather concatenation arithmetic (verified the layout identity), the `0.5*(S+Sᵀ)` symmetrization disclosed with mutation evidence, and the solve-side reduction and local back-substitution. Matches `docs/dev/schur-slab-solver.md` line for line; the whole-grid `nranks==1` path duplicates `periodic_laplacian` verbatim for bit-identity.
- **I2 audit of every refusal in the distributed linalg code.** `from_triplets`' refusals: local, and nothing later in the call performs a collective — clean per the rule. `SchurSlabSolver::factor`'s band check: pure function of `row_ownership`, identical on every rank, zero collectives — the `c11ac18` fix is present and correct. The rank-varying conditions are agreed by `ranks_not_ok` **before** the guarded allgathers. Post-allgather failures either occur identically on every rank or have no later collective in the call. `JacobiPreconditioner::from_matrix`'s refusal: no collective in the call. `pcg`/`gmres`' early returns are decided from *global* reductions — rank-consistent. The one gap found is NL-6. The `c11ac18` fix's class does **not** recur elsewhere in this layer.
- **PCG recurrence**: exact Hestenes-Stiefel; the recompute-before-report and resynchronization discipline is implemented as documented and pinned by `PcgRecomputesTrueResidual` with an independently recomputed check.
- **GMRES(m) structure**: MGS Arnoldi, Givens applied in correct rotation order, back substitution over the rotated triangle, right preconditioning with the final `M⁻¹` map, unconditional fresh `r0` at every restart boundary, no silent cap (verified the `max_iterations=1` trace exits with `E-LINALG-NO-CONVERGENCE`), breakdown handled defensively and honestly disclosed as unexercised.
- **from_triplets dedup/sum semantics, column split, ghost pattern**: duplicates summed in both blocks, unique ascending off-process columns, owner resolution by one `upper_bound` — matches `linalg-distributed.md`; `apply`'s ghost-then-two-CSR-products and `diagonal()`'s no-communication claim both verified.
- **comm_mpi two-phase pattern**: group-by-owner, counts Alltoall, values Alltoallv; pack/unpack maps derived once and read consistently in `update` — line-by-line matches the doc's derivation; reversed/non-identity ghost order exercised at tier 0 and tier 1.
- **Least squares**: column-pivoted Householder QR correct including the rank-truncation threshold relative to the leading pivot, downdate-with-recompute, dropped-columns-exactly-zero contract (pinned on both backends), non-finite column norms degrade conservatively; `m >= k` enforced on public entry points, deliberately not on `least_squares_into` (R-45) with the `m<k` path bounds-checked and regression-pinned.

## 4. Test-coverage assessment

**Strong.** Every public behavior mapped has at least one firing test: both Krylov solvers iterate-for-iterate
against Eigen plus independent residual recompute (tier 0) and convergence + recompute over real MPI (tier 1);
both Krylov refusals fired; all Schur refusal paths fired *with allgather-count assertions* at tier 0 (the
stranding regression is genuinely pinned); Schur accuracy measured against the whole-grid reference at 2/3
partitions with a wrap-only-forcing case, plus the decomposed-species-core verification tests; container
semantics measured against independently computed ground truth at tier 0 and closed-form references at tier 1;
least-squares oracle-comparison + rank/zero contracts on both backends; the accelerator family's contract
surface is the best-covered part of the layer (57 cases including allocation fences and mutation-killed
divergence probes); waveform support/order/allocation contracts all pinned.

**Gaps (in priority order):**
1. `DiffusionSolver` cache reuse is never tested across a changed operator input — the `FsiStokesLuCache` pattern exists for the *other* solver and was not replicated here (NL-1).
2. `restart == 0` (NL-2) and `restart`-vs-`max_iterations` boundary shapes beyond the 1-step cap are untested.
3. `E-LINALG-SCHUR-BACKEND` (NL-5) and `E-LINALG-MPI-ALLTOALLV` are refusals no test fires.
4. No MPI-level test exercises the *agreed* interior-factorization failure (tier 0 covers it with the seeded-vote fake; the real-MPI row covers only the band refusal, and its comment is stale — NL-3).
5. `DistSparseMatrix::apply` aliasing is untested and undocumented (NL-11).
6. No allocation fence covers the Krylov/comm hot path (NL-7) — the fences exist for accelerators, waveforms, the field pipeline, and the Runner sweep loop, but the one hot kernel this layer itself owns is unfenced.
7. Two bit-tight assertions sit on re-associated reductions (NL-10) — the same fragility D30 already recorded for contraction.
