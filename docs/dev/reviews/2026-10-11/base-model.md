## 4. Test-coverage assessment

**Strong.** Every refusal in `multiscale`, `Rational`, `Units`, version negotiation, and the descriptor's validated enums has a firing test; past defects (R-04, R-15, R-16, R-18, R-19, N-base-model-1/2) each carry a regression test naming the original failure mode; the three-leg round trip against frozen golden bytes is exemplary narrow-waist practice.

**Gaps, in priority order:**
1. `from_yaml` robustness against malformed-but-loadable documents (BM-2): no test omits a required key or supplies a wrong-typed scalar.
2. Corrupted-descriptor enum coverage is asymmetric (BM-3): five enum bytes have corruption tests; six others have neither validation nor tests.
3. The `check_channel` graph path is only tested with `Conservation::None` fields (BM-1): the Conservation stage has never fired through `validate()`/`lower()` in any test.
