## 2. Checked and found clean

- **The recursion's decisions are otherwise all global.** Axis selection from Allreduced extents with `depth % 3` fallback; median target/bounds from the Allreduced histogram; tie-walk inputs from two Allgathervs and an Allreduced tie weight — every branch condition gating a collective is a pure function of globally-reduced data, identical on every rank. No empty-subset early return exists; base case checked first, exactly as partitioning.md:53-58 claims.
- **Median/refine edge cases.** Degenerate all-identical coordinates, all-empty-ranks, `refine_iterations <= 0`, `num_buckets < 2`, zero-width refined bucket (the `width <= tol` break precedes the `1/dx` in `accumulate_histogram`, so the `0 * inf = NaN → static_cast<int>` UB path is unreachable), bucket-index overflow — all handled by the same code path, matching partitioning.md:85-88.
- **FMA determinism claims verified as stated.** `(c - cur_lo) * inv_dx` is two separate statements with no `a*b+c` pattern; the one genuine FMA candidate is host-only scalar code compiled once. The oracle computes identically.
- **The I5 determinism question, answered: RCB *is* bit-identical across thread counts by construction.** Every accumulation that could observe thread order is `int64` (associative and exact); min/max are order-independent; all FP that steers decisions runs host-side in one code path. The omp legs re-run the oracle-parity suite at 1 thread and all cores, so the claim is also *tested*. (PS-12 records the one wrong sentence in the surrounding rationale.)
- **Oracle parity is genuine.** rcb_oracle.hpp reproduces rcb.hpp/median.hpp expression-for-expression, so the bit-parity tests over five fixture families and the P-independence properties really do pin the port, including the gnomonic transform via an independently-written host projection.
- **collectives.cpp.** `kNullComm` legs are pure identities; `resolve()` FUSE_ASSERTs the every-caller-must-short-circuit invariant; allgatherv layout matches what rcb.hpp assumes, and the `offset_gids == offset_ws` FUSE_ASSERT guards the two-call pairing.
- **centroids_of cross-rank discipline** — the one place in the layer that *does* reconcile correctly: `dimension()` agreed by MAX *and* MIN before any entity is read, so `E-PART-MIXED-DIM` fires identically on every rank; no hang. The `dimension()`-not-scan design claim is honored and pinned by both mesh_adapter tests.
- **repartition bookkeeping** — single comm forced, owned-only centroids align 1:1 with `dest` sizing, host↔device deep_copies layout-matched, uniform-weight fill correct, and the migration half inherits `migrate`'s Allreduce(MIN)-reconciled rejection — no I2 hole on that path.
- **I7 / layering, verified by grep + gate.** No public header in either layer includes `mpi.h` or any ArborX header. **The documented duck-typing resolution still holds**: `include/fuse/search/mesh_adapter.hpp` includes no `fuse/backend/...` anywhere; `MeshLike` is structural, `centroid` used only unevaluated, and both the real `MeshView` and the unrelated `FakeMesh` instantiate it. partition's own mesh_adapter.hpp and repartition.hpp include `fuse/backend/*` — legitimate downward edges.
- **BoxIndex construction/query correctness.** Mixed-dim refusal matches doc; empty-build handled; `to_result`'s per-query sort delivers the documented ascending order; moved-from `BoxIndex` safe; `intersects(Point)` boundary behavior pinned by exact-boundary tests.
- **`padded`/`classify_dim` exact-zero convention** — does exactly what search.md:99-121 documents.
- **`element_boxes`** — `dim + 1` corner buffer matches the `simplex_points` contract; refusals fire under tests; non-convex cells bounded via simplex decomposition, ghosts excluded.
- **Distributed query result integrity** — `TagWithRank` tags the *owner's* rank, hits sorted by `(rank, index)`, zero-box/zero-point ranks still enter the collectives (no local shortcut — the discipline is correct *here*, which makes PS-1's check-before-collective the outlier), `kNullComm` matches the single-rank contract.
- **Weighted-median loop break conditions** computed from globally-reduced values only — no rank can break where another continues (given PS-3's caveat about the iteration *cap*).

## 4. Test-coverage assessment

**partition — strong for a Tier-0-only layer, with three named holes.**
Covered: bit-parity against an independent oracle across all five named fixture families, typed over
every enabled execution space, at num_parts ∈ {1…13} including non-divisor counts; exact-imbalance
(not tolerance) checks; all documented degenerate shapes in both library and oracle; comm-size
independence of the oracle at P=1..5; mesh-adapter happy paths including the skin-vs-volume trap;
repartition identity at kNullComm; refusals `E-PART-NUM-PARTS`, `E-PART-SIZE-MISMATCH` (both mismatch
flavors), `E-PART-NO-MPI`; `E-PART-MIXED-DIM` compiled for MPI with a genuine two-mesh disagreement
fixture; omp legs at 1 and all cores; five killed mutants with one honestly marked NOT-ASSESSED (needs
MPI). Holes: (1) `E-PART-NO-ENTITIES` never fired (PS-4); (2) no test anywhere exercises a *one-rank*
refusal under a real communicator — the I2 hazards PS-2/PS-3 are structurally invisible to the suite;
(3) `repartition` is tested only at `num_parts == comm size` (the identity), so the doc's constraint
(PS-6) has no behavioral pin in either direction. The MPI tests' parity design (each rank re-derives the
full comparison, no rank-0 funnel) is notably good.

**search — thorough for the serial facade, thin exactly where PS-1 lives.**
Covered: point queries vs an independent brute force in 1/2/3D with a non-vacuity floor; boundary
semantics pinned three ways; k-NN against a tie-*tolerant* reference that checks the property actually
owed — the correct design for distance-zero ties — plus the k>size cap and refusal; per-query sort
determinism; empty index; every refusal code except the distributed-MPI one; adapter proven against
both the real backend and a structurally-unrelated fake (proving the concept is genuinely duck-typed);
four killed mutants. Holes: the distributed path's only tests are compiled-not-run, and even when run
they feed well-formed input to every rank — so the one behavior unique to the distributed API (what
happens when ranks *disagree*) has no test that can fail, in this sandbox or on a host. Given I2's
enforcement model explicitly demands "parallel tests that assert an error rather than a hang," that is
the layer's most consequential gap: add a two-rank test where exactly one rank submits mixed-dim boxes,
asserting every rank returns `E-SEARCH-MIXED-DIM` within the timeout, as part of the PS-1 fix.
