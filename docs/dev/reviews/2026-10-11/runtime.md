## 2. Checked and found clean

- **I2 core loop, instruction level**: `step_period`'s post-failure walk executes `is_collective` ops and skips locals; an Epoch failure returns only after `reconcile_epoch` completed; `run_region`'s body loop applies the same rule and its *advance* failures carry through to the sweep's residual agreement before exiting. R-09/R-10 fixes present as described.
- **Dependence rule**: `downstream_of` built as documented (transitive closure over channel edges), `block_advances_from` blocks origin + downstream, applied to both tick loops and to region failures ("origin = every member the region re-advances"); out-of-range origin blocks everything. Pinned by `Runner.AFailedStepBlocksOnlyWhatReadsFromIt`.
- **Verdict discipline**: `step_failure` is monotonic within a period (first failure kept, reset only when reported at period end); no verdict-clearing pattern anywhere in the layer.
- **Epoch machinery**: MPI-free, unit-tested; participant lists derived identically from the graph on every rank; tag below `MPI_TAG_UB` checked at setup against the same communicator the reduction uses (R-32 fix in place); no communicator held past `attach_comm_graphs`; setup's status-agreement Allreduce correctly brackets the rank-divergent phases.
- **D25 / window block ownership**: `window_export_meta` stores `export_consumer_hosted` and — one level further, as documented — `b.window_hosted` is re-resolved **per block from that block's own channel's target**. Pinned by `WindowHosting.*` (incl. the fan-out case) and `parallel.window_runner_mpi.{2,3}`.
- **Deterministic reductions**: per-sweep block norms use `deterministic_norm_squared[_diff]` with setup-sized scratch; the WindowCoupler's named measures reproduce the identical chunk order bit-for-bit; no plain `parallel_reduce` anywhere in the layer.
- **Rollback verification**: byte-exact `memcmp` (no tolerance) after every `restore_state()`; registered-storage caveat honestly documented in all three places.
- **D7 driver envelope**: `E-RT-WINDOW-STRADDLE` and `E-RT-WINDOW-LONGSTEP` both refused and tested in `WindowCoupler::create`; the STRADDLE half is correctly mirrored on the Runner and tested (see RT-3 for the LONGSTEP asymmetry).
- **Coroutine/resume machinery** (D12/D13): symmetric-transfer task with size-keyed frame arena (allocation-free steady state, disclosed reasoning), `active_handle` discipline matches the documented rule; `run_period` refuses external components by name; `E-RT-RESUME-INVARIANT` backstop present.
- **Device staging correctness**: lane aliasing by host pointer makes in-place ops single-lane correct; widening writes dirty data back before re-staging; fault path launches zero-length kernels only; lane count (4) provably suffices for the widest instruction; `remap_csr_device` indices parallel to `remap_weights` and bounds-checked at use.
- **Conventions**: no iostream in the layer; `FUSE_ASSERT`/`FUSE_THROW` used per convention.
- **Peer-failure → window bystander gap**: recorded (D33 closing note) and confirmed still as described.
