# Developer Guide

This guide describes the active CMake target and the correctness contracts new work must preserve.

- [Architecture](architecture.md) maps subsystem ownership and active seams.
- [Build and Test](build-and-test.md) covers dependencies, registration, CTest fixtures, MPI tests, and documentation builds.
- [Distributed Correctness](distributed-correctness.md) records collective, ownership, ghosting, assembly, and checkpoint invariants.
- [Contributing](contributing.md) gives the expected implementation and review workflow.

Automation-specific instructions are in the repository root `AGENTS.md`.
